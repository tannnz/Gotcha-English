# 引导式写作

1. 确定写作任务、受众和目标结构或表达。已有条件直接沿用，给少量写作提示后请用户提交初稿。
2. 用户卡住时，每次只补充一个提纲、问题或句首，等用户继续写。完整范文留到用户明确索要时提供。
3. 收到初稿后，反馈内容是否达到目标、结构是否清楚，以及最影响表达的语言问题。分别说明需要纠正的错误和可选的风格调整。给出足够具体的提示，请用户自己修订。
4. 等用户提交修订稿，检查本次修订是否解决了关键问题，给简短反馈后收尾。用户要求先结束时，按现有稿件简短总结。
