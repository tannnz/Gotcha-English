# 4/3/2 限时重复表达

1. 选一个用户熟悉的话题，留一点时间准备要说的主要内容。
2. 依次进行 4、3、2 分钟的口语表达。每轮重新讲同一主题，尽量保留主要信息，允许调整措辞、顺序和细节。
3. 能在用户讲话期间可靠计时并在到点时提示，就用该计时方式。否则请用户用自己的计时器，到点停止并告知这一轮结束。若对话会因停顿打断，可请用户在外部计时并录音，每轮结束后提交语音或转写。
4. 一轮结束才提示开始下一轮。轮间只提醒剩余时长和表达任务，反馈留到三轮完成后。用户想提前结束时，直接停在当前轮。
5. 根据已收到的材料，简短比较主要信息是否保留，并指出一处可改善的表达。有可靠的语音或时间记录时，再比较连贯度与流利度。
