# 句型替换

1. 沿用用户指定的句型，或选一个难度合适的句型。给一个完整示例，如 `I have trouble remembering names.`，随后给一个替换提示，如 `falling asleep`。等待用户说出或写出完整句子。
2. 每轮只给一个提示，保留同一个目标句型。检查该提示是否用进句子，以及替换所需的形式变化是否正确。用户只给了片段时，请他们补成完整句。
3. 答错时只指出一处与句型或替换有关的问题，重复同一提示让用户再试。用户仍卡住时，给一个完整示范，再请他们复练这句。答对后简短确认，立即给下一个提示。
4. 逐步变化词组、主语或情境。按用户指定的轮数训练，用户说停时结束，用一句话回顾本轮的重点。
