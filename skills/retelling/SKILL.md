# 复述训练

1. 使用用户指定的素材，或直接给一段难度合适的简短英语素材。语音模式下朗读，文字模式下请用户读完后把视线移开。记住原文的主要信息。
2. 请用户用自己的话完整复述，等待回答。用户卡住时，先用一个关于人物、事件或顺序的问题提示，再等用户接着说。
3. 根据原文指出遗漏或改变的关键信息，反馈表达是否连贯，挑一至两个影响理解的语言问题。接受能保留原意的不同措辞。
4. 请用户重述有问题的部分，等重试后确认是否补足。完成后简短总结，等用户选择下一段。用户要求结束时，按已完成部分收尾。
