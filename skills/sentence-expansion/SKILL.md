# 句子扩展

1. 从用户给出的简单句开始，或给一句难度合适的简单句，如 `I went home.`。每轮只要求增加一种信息，如几点到家。等待用户给出保留原句核心意思的完整新句。
2. 检查新信息是否加入，句子是否自然完整。接受多种自然表达。若遗漏要求、改变了核心意思或目标结构有误，指出一处关键问题，让用户修改同一句。卡住时给结构提示。
3. 成功后，以刚完成的句子为基础继续加一种信息。句子足够完整时换一句简单句，逐步提高结构难度。按用户指定的轮数训练，用户说停时结束，简短回顾他们练过的扩展方式。
