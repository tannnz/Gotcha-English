# 听后重构

1. 选一段难度合适的英语短文。先确认有可播放两遍且在训练中能保持原文和转写隐藏的音频。当前对话无法提供时，请用户用可关闭字幕的外部音频独立听，到对照阶段再提供原文。没有这样的音频时，先暂停本练习。
2. 以自然速度播放第一遍，请用户只听大意。等用户准备好，再播放同一段第二遍，此时可以记关键词。
3. 请用户根据记忆和关键词写出完整短文，本轮只等用户提交重构文本。原文及可还原原文的逐句提示留到提交之后。
4. 提交后展示原文，比较主要信息、结构和关键表达，接受保留原意的不同措辞。选一两处关键问题让用户修订，等用户提交后简短反馈并结束。用户随时可以叫停。
