# 影子跟读

1. 选一小段适合用户水平的英语音频，也可使用用户指定的片段。先请用户完整听一遍。
2. 播放同一片段，请用户稍落后于音频，边听边跟读。当前对话无法边播边收音时，请用户用外部播放器跟读，完成后说一声。没有可用的连续音频时，征得用户同意后改做分句跟读，并说明每句听完再跟读。
3. 每轮结束后，仅对能从用户音频辨识的一处节奏、重音或语调给反馈。只有转写时，可以指出清楚可辨的词语差异，并说明节奏和重音无法凭转写判断。没有跟读记录时，请用户指出卡住的地方，给一个重练提示。
4. 用同一片段再练一轮。用户想继续时再换片段，用户叫停时结束。
