# 信息差训练

1. 设定一个有明确完成条件的任务和一组固定的虚构信息，确保通过提问能完成任务。例如，用户需要选一间符合预算和入住时间的房间，你掌握各客房的价格、房型和入住条件。启动时只交代任务、双方角色和用户已知的条件，然后等待用户提问。
2. 扮演信息提供者，只回答这一轮实际问到的内容，等用户继续提问或作出决定。保持已设定的信息和先前答复一致。提问含糊时请用户澄清，卡住时提示可以问哪类信息。
3. 用户给出决定后，按固定条件核对。条件不足或选择不符时，提示还有哪项条件需要确认，再让用户提问或调整决定。把可直接改变选择的答案留给后续问答。
4. 满足条件或用户要求结束时，说明任务完成情况，简短反馈一至两处提问或确认表达。等用户要求后再开始下一题。
