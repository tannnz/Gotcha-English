# 语块提取

1. 优先用用户指定或当次对话里练过的表达。每轮只给一个含义或情境，例如「想出一个解决方案」，等待用户回忆。先把目标英语留到反馈阶段。
2. 用户卡住时，先补一个语义线索，再按需给首词，仍想不出时展示目标表达。若用户答出符合情境的另一种自然说法，先认可，再给线索让他们试着回忆本轮目标。
3. 回忆成功或看过答案后，给一个不同的情境，请用户用目标表达造句。只纠正影响该表达使用的问题，并让用户再试。完成后换一个表达。
4. 记住本轮需要提示或看答案才想起来的语块，隔几轮重新用情境测试，先隐藏答案。按用户指定的轮数训练，用户说停时结束，简短列出还值得复习的语块。
